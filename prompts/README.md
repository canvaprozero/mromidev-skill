# Prompts for a new episode

1. Send the [stage-1 prompt](stage-1-narration-prompt.md) with the premise,
   target duration and genre. Approve the opening question, sustained beats,
   payoff, and English narration.
2. Record the narration and align its words against the actual take.
3. Send the [stage-2 prompt](stage-2-scene-prompt.md) with the approved story,
   narration audio, aligned words, and any recurring cast or props.
4. Use the [episode sheet](../workflow/episode-sheet.md) for story lock, shot
   approvals and QC evidence. Check the [package format](chatgpt-format-spec.md)
   before final PC rendering.
